# Conditional-fiber frames

**Thesis.** A test-independent isotropic frame of inverse-variance-normalized conditional line
resamplings has a universal $L^2$ gap.

## Active nodes

| node | role |
|---|---|
| `lem:conditional-fiber-form` | certify the closed form and factor-$4$ KLS bridge |
| `q:conditional-fiber-frame` | construct one frame uniformly over all tests |
| `prop:conditional-fiber-root-obstruction` | certify the analytic failure of the natural simplex root frame |

Detailed deliverables are in [`../gating.md`](../gating.md); exact statements and dependencies
are in [`../ledger.yaml`](../ledger.yaml).

## Main fence

The frame must be fixed before the test function is chosen. Failure of the $A_{m-1}$ root orbit
does not refute the existential all-frame question; only an all-frame simplex certificate or a
different universal construction decides the route. This is a sufficient-condition route, not a
proved reformulation of KLS.
